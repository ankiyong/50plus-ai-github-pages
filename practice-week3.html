Google Stitch 열기 ↗

PRD와 디자인 요청을 함께 전달

  1. 확정한 PRD와 원하는 화면 설명을 함께 입력해요.
  2. Stitch가 왼쪽 채팅에 제안한 다음 작업 중 필요한 것을 골라요.
  3. 조건 선택 → 추천 버튼 → 결과 카드 순서와 불편한 부분을 구체적으로 수정해요.
  4. 오른쪽 위 프로토타입 버튼(원 안의 삼각형)으로 화면을 연결해요.

실습 4 / 7 웹페이지 구현

AI Studio로 구현

디자인과 PRD를 함께 전달해 실제 기능을 만들어요.

디자인 + 같은 PRD를 전달해요

  1. Stitch의 Export 메뉴에서 AI Studio를 고르고 Build with AI Studio를 눌러요.
  2. AI Studio에 첨부된 Markdown(Stitch 화면 코드)과 아래 프롬프트(PRD)가 함께 왔는지 확인해요.
  3. PRD와 메뉴 목록이 빠졌다면 붙여넣고, 오른쪽 구현 요청을 보내요.
  4. 바꾸고 싶은 점은 채팅에 현재 문제와 원하는 변경을 구체적으로 적어요.
  5. 수정이 끝난 화면에서 요청한 변경이 반영됐는지 확인해요.
지도·현재 위치 기능을 넣었다면 위치 접근 요청이 나올 수 있어요. 항상 나오는 단계는 아니에요.

메뉴명과 제공 기능은 계정·현재 화면에 따라 다를 수 있어요. 디자인을 내보냈다고 추천 기능까지 완성됐다고 가정하지 않아요.

실습 5 / 7 동작 확인

실제 기능 확인

레이아웃을 먼저 보고, 추천 버튼을 눌러 PRD의 완성 기준과 비교해요.

먼저 레이아웃 확인

  1. 필요한 버튼 · 추천받기 등 PRD에 적은 버튼이 빠짐없이 있나요?
  2. 원하는 위치 · 조건을 고른 뒤 추천 버튼을 바로 누를 수 있나요?
  3. 잘림·겹침 · 휴대폰에서도 글자와 버튼이 온전히 보이나요?
위치가 다르면 현재 위치 → 원하는 위치를 구체적으로 알려 수정해요.

세 가지 상황으로 직접 확인해요
