## 1주차 수강생 실습

수강생에게 `practice-week1.html` 주소를 안내합니다. `#activity-1`부터 `#activity-6`까지 특정 실습으로 직접 이동할 수 있습니다.

1. 재료로 요리 추천받기 (제로샷)
2. 예시 따라 쓰기 (퓨샷)
3. 역할 정해 사진 정리하기 (수강생이 역할 직접 입력)
4. 풍경 이미지 설명하기
5. 소개 카드로 웹 기술 익히기 (HTML → CSS → JavaScript, 단계별 프롬프트 복사)
6. 만들고 싶은 것 정리하기

입력한 내용과 완료 표시는 사용하는 기기의 브라우저에 저장됩니다. 강의안의 시연 데이터와 다른 저장 공간을 사용합니다. 자동 저장을 사용할 수 없으면 안내 문구가 나타납니다. 상단의 ‘내 실습 내용 저장’으로 텍스트 파일을 내려받을 수 있습니다.

프롬프트는 사용 중인 AI 서비스에 붙여넣어 실행합니다. 실습장 자체는 AI를 호출하지 않습니다.

## 2주차 수강생 실습

수강생에게 `practice-week2.html` 주소를 안내합니다. 기획 시트는 강사가 제공하며, 실습장에서 기획 시트를 새로 생성하지 않습니다.

대상과 문제 → 필수·선택 기능 → 기획안 → 웹페이지 제작 → 실행·캡처·수정 → HEX 색상 → 디자인 레퍼런스 → 최종 확인 순서로 진행합니다. 각 단계에서 수강생이 먼저 판단하고 AI의 질문·대안을 검토한 뒤 결정을 기록합니다. 복사할 수 있는 프롬프트 8개, HTML에 포함된 실제 참고 사이트 캡처 2개, 색상 미리보기와 완료 확인을 포함합니다.

AI가 실행 도구를 사용할 수 있으면 직접 열고 클릭하고 캡처하도록 요청합니다. 도구가 없으면 수강생이 실행·캡처하여 AI에 전달합니다. 화면 캡처와 실제 기능 동작 확인을 구분합니다.

실습 예시는 제공된 가상 이력서로 만드는 자기소개·이력서 페이지입니다. 자기소개 읽기, 경력·학력·자격 확인, 프로젝트·역량 확인, 이력서 PDF 다운로드, 연락 방법 확인을 첫 공개의 필수 기능으로 제시합니다. 원본에 없는 경력이나 성과를 만들지 않고, 자료의 사실과 기획상의 가정을 구분합니다. 기획 시트는 Google AI Studio의 Drive, 컴퓨터에 내려받은 PDF는 Upload files로 전달하는 경로를 안내합니다.

PDF 다운로드는 원본 파일이 실제 저장되고 2쪽 모두 열리는지 확인합니다. 배포할 때 HTML과 PDF를 함께 올리고, 공개 주소에서도 다시 확인합니다. 예시 페이지의 이메일은 가상 주소이며 링크는 메일 앱을 여는 용도입니다. 실습장에서 기존에 편집한 요청문과 메모는 유지되며, 수정하지 않은 이전 기본 요청문만 새 예시로 바뀝니다. 요청문별 ‘예시로 되돌리기’로 새 기본값을 불러올 수 있습니다.

## 3주차 수강생 실습과 강의안

`practice-week3.html`에서 최소 정보 질문 → 예시 답변 → PRD 검토·확정 → Stitch 디자인 → AI Studio 구현 → 기능 확인 → 취미 찾기 독립 실습 → 서로 사용하고 개선하기 순서로 진행합니다. 각 활동에 직접 연결할 수 있는 주소는 `#activity-1`부터 `#activity-8`까지입니다. 요청문 편집, 메모, 완료 상태는 3주차 전용 브라우저 저장 공간에 보관하며 확인 기록을 텍스트로 내려받을 수 있습니다.

강의안은 24장입니다. 기획·MVP·PRD의 정의를 먼저 설명하고, 실습 1(점심 메뉴 추천)을 PRD 작성 → 디자인 → 구현 → 확인의 네 단계로 진행합니다. 실습 2(취미 찾기)도 같은 흐름으로 핵심 기능부터 정의합니다. PRD 요약 문서 이미지는 클릭해 확대할 수 있습니다. 장표와 클릭 설명을 포인터·키보드·본문 클릭으로 이동하며, 현재 수업 단계, 목차, 강사 메모, 전체 보기, 전체화면과 인쇄를 지원합니다. 링크·입력·복사·확대·텍스트 선택·드래그는 장표 이동과 구분합니다. 비밀번호 없이 열립니다.

1~3장은 수정한 참고 장표의 카드 높이와 여백을 반영했습니다. 3장은 MVP 정의와 세 단계 도식만 보여 줍니다. 4장은 포인터 입력 세 번으로 개발 후 결과 불일치 → 처음 기획으로 되돌아가는 재작업 → 기획·기능을 먼저 정의한 제작 흐름을 보여 줍니다. 긴 주황 화살표와 짧은 청록 화살표로 재작업과 부분 개선의 차이를 설명합니다. 이전 입력·다시 보기를 지원하며 전체 보기와 인쇄에서는 완성된 도식을 표시합니다. 동작 줄이기 설정에서는 선을 즉시 표시합니다.

7장은 작성한 PRD를 바탕으로 화면을 디자인하는 준비 → 제작 → 선택의 세 단계를 보여 줍니다. 8장 `Google Stitch란?`은 설명·참고 자료 입력 → 화면 초안 생성 → 버튼 위치·색상 수정 → 디자인 선택을 포인터 입력으로 설명하는 모션 도식입니다. 도식은 수업용 디자인 예시이며 실제 서비스 화면이 아닙니다. 도구 열기 링크, 이전 입력·다시 보기, 전체 보기·인쇄, 동작 줄이기를 지원합니다. 뒤 장표와 목차는 9~24장으로 이어집니다.

강의안 6장은 첨부 레이아웃에 맞춘 PRD 작성 한 장입니다. 처음에는 `웹 페이지 개발 prd 작성을 위해 필요한 최소 정보 알려줘`와 여섯 질문을 보여주고, 다음 포인터 입력에서 오른쪽 답변 예시를 공개합니다. 다음 입력에서 하단에 3단계 프롬프트 `정리된 내용 prd 문서로 작성해줘`를 공개합니다. 3단계 다음에는 디자인 장표로 이동합니다. 이전 입력은 한 단계씩 되돌리고 다시 보기는 1단계로 돌아갑니다. 기존 별도 답변·문서화·확정 장표는 통합했습니다. 수강생 실습장에서는 원문 요청과 전체 PRD의 편집·복사·내려받기를 계속 제공합니다. 첨부 예시의 날씨·근처 식당·지도·메뉴 사진은 기획 답변이며, 기존 고정 메뉴 작동 예시의 구현 범위를 변경한 것은 아닙니다. 실제 AI 응답은 서비스와 대화에 따라 다르며 예시는 수업용 가정입니다. `assets/week3-data.js`에서 강의·실습·작동 예시의 요청문과 메뉴 데이터를 공유합니다.

`lunch-example.html`은 예산(8,000·10,000·15,000원 이하)과 음식 종류(한식·중식·양식·상관없음)를 선택하면 정해진 예시 메뉴 12개 중 조건에 맞는 최대 3개를 보여줍니다. 8,000원 이하·중식은 짜장면과 볶음밥, 8,000원 이하·양식은 결과 없음으로 확인할 수 있습니다. 예시 가격이며 실제 식당이나 실시간 AI API를 사용하지 않습니다.

Stitch 사용 안내는 생성·수정·전달의 개념과 요청문을 도식으로 설명합니다. 실제 서비스 화면을 재현한 것이 아닙니다. AI Studio 연결 기능은 사용하는 계정과 현재 화면에서 확인하며, 디자인과 같은 확정 PRD를 함께 전달합니다. 직접 연결이 없으면 사용 가능한 화면·코드 결과물을 전달하도록 안내합니다. 독립 실습의 취미 추천은 관심·시간·예산·활동 방식·시기를 중심으로 정하고 나이·성별은 필요성을 판단해 선택 입력으로 다룹니다.

## 게시

HTML 파일과 assets 폴더를 저장소 루트에 함께 둡니다. 현재 저장소는 master 브랜치의 루트에서 GitHub Pages를 게시합니다. 수정한 파일을 커밋하면 자동으로 배포합니다.

## 강의안 열기

1·2·3주차 강사용 강의안은 비밀번호 없이 바로 열립니다. 주차 선택 화면의 ‘강사용 강의안’ 링크를 사용하거나 각 HTML 주소로 직접 접속할 수 있습니다. 새로고침과 재방문에도 비밀번호를 요구하지 않습니다.

강의안은 일반 HTML 파일로 게시합니다. 해당 HTML을 직접 편집해 저장하고 게시하면 됩니다. 수강생 실습장도 비밀번호 없이 사용합니다.

## 1주차 포인터와 마우스 이동

강의안에서 리모컨의 Page Down/Page Up, 방향키, Space/Shift+Space, Enter, N/P, Backspace를 지원합니다. 슬라이드 본문 왼쪽 클릭은 다음, 오른쪽 클릭은 이전 설명으로 이동합니다. 인포그래픽 설명은 한 단계씩 진행됩니다. 입력창·버튼·텍스트 선택·드래그·열린 대화상자의 기본 동작은 유지합니다.


## 2주차 강의안 조작

모든 장표에서 포인터·리모컨의 방향키, Page Down/Page Up, Space/Shift+Space, Enter, N/P, Backspace로 이동합니다. 본문 왼쪽 클릭·터치는 다음, 오른쪽 클릭은 이전 설명으로 이동합니다. 일반 장표와 Q&A·MVP·지침·메모리·AI Studio·배포 모션 모두 지원하며, 단계가 있는 장표는 설명부터 한 단계씩 진행합니다. 버튼에 초점이 남아 있어도 방향키·Page Down/Page Up은 이동에 사용하고, Enter·Space는 해당 버튼을 실행합니다. 길게 누르는 반복 입력으로 여러 장을 건너뛰지 않습니다.

목차·전체 보기·강사 메모·전체화면·인쇄를 지원합니다. 입력창, 복사·확대·재생 버튼, 링크, 텍스트 선택·드래그, 열린 대화상자의 기본 동작은 유지합니다. 학생 실습장 링크는 상단에 있습니다.

1~4쪽은 지난 시간 질문과 답변입니다. 개발자 도구의 역할, 일반 사용자에게도 개발자 도구를 제공하는 이유, 웹페이지의 앱 전환, 카페24 연동을 질문별로 설명합니다.

5~7쪽은 ChatGPT의 맞춤형 지침·메모리·이번 요청을 설명하는 클릭 모션입니다. 맞춤형 지침은 설정에 직접 정해 둔 답변 방식, 메모리는 대화에서 기억해 둔 사용자 정보·선호, 이번 요청은 지금 답변에 새로 부탁한 내용으로 구분합니다. 처음 화면에서 멈추며, 본문 클릭·방향키·하단 ‘다음 설명’ 버튼으로 한 단계씩 진행합니다. ‘이전 설명’과 ‘다시 보기’로 되돌릴 수 있고, 마지막 설명 뒤에는 다음 장표로 이동합니다. 전체 보기와 인쇄에서는 완성된 도식을 보여주며 발표 보기로 돌아오면 진행 상태가 복원됩니다. 질문·답변과 지침·메모리의 상세 설명은 기존 ‘강사 메모’에서 확인합니다.

기존 강의는 8쪽 표지부터 이어집니다. 9쪽은 기획(대상과 문제 정의) → 기능 정의 → 설계 → 디자인 → 구현 → 배포의 전체 과정을 보여줍니다. 하단의 여섯 단계 표시에서 현재 장표가 다루는 단계를 강조합니다. 표지·전체 과정·수업 흐름에서는 ‘전체 과정’을 표시합니다.

11쪽은 오늘 사용할 도구인 Google AI Studio를 소개합니다. 첨부 화면의 실제 워드마크와 함께 브라우저에서 질문하기, 내 자료를 첨부하기, 요청을 고치며 비교하기를 설명합니다. 14쪽은 기존 13쪽의 기획 템플릿 작성 안내입니다. 바로 뒤인 15~19쪽에서 첨부된 화면 순서대로 Playground → ＋ → Drive → 작성한 사본 선택 → 첨부 확인·검토 요청·Run을 보여줍니다. 현재 모델명이나 요금·무료 한도를 단정하지 않습니다.

24쪽은 MVP의 뜻, 25쪽은 MVP를 사용하는 이유를 설명합니다. 전체 과정과 두 MVP 모션그래픽은 각각 10초 재생한 뒤 멈춥니다. 일시정지·다시 보기를 지원하며, 다른 장표로 이동하면 재생이 멈춥니다. 전체 보기와 인쇄에서는 완성된 도식을 보여줍니다.

10쪽에서 자기소개·이력서 완성 예시와 원본 PDF를 엽니다. 기획·필수 기능·MVP·제작·수정·색상 적용의 예시는 이력서 페이지로 연결됩니다. 24~25쪽의 MVP 모션은 소개와 경력을 읽고 PDF를 받는 핵심 행동, 다운로드 버튼의 문구를 개선하는 과정을 보여줍니다. 26쪽에서는 PDF를 실제로 내려받아 여는 완성 기준을 확인합니다. 29쪽의 제작 요청에는 확정 기획안과 원본 PDF를 함께 전달합니다.

35쪽의 디자인 적용 프롬프트는 ‘첨부된 디자인 참고해서 내 웹 페이지에 적용해줘’이며, 복사와 크게 보기에서도 동일한 문구를 사용합니다.

36~39쪽은 서버와 배포를 설명하는 클릭 모션입니다. 내 컴퓨터 → 서버 → 방문자의 흐름, 직접 배포와 GPT에 부탁하는 배포의 공통 원리, 진행 방법의 차이, GPT 이용료와 웹 운영비를 차례로 설명합니다. 각 장은 두 번 클릭하면 설명이 완성되며 하단 현재 단계는 ‘배포’를 표시합니다. 앞의 지침·메모리와 동일한 이동·다시 보기·전체 보기·인쇄·강사 메모 기능을 사용합니다.

배포 설명은 GPT에 배포 도구가 연결되어 있고 내 호스팅 계정에서 작업을 허용한 상황을 가정합니다. 특정 서비스의 현재 요금이나 무료 한도를 제시하지 않으며, ChatGPT 이용 조건·호스팅 요금제와 사용량·선택한 도메인이나 AI API 등의 비용을 구분합니다.
