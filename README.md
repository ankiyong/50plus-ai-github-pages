# 50플러스 AI 교실 · GitHub Pages

1·2주차 강의안과 수강생 실습장을 분리한 정적 웹사이트입니다.

## 페이지

- `index.html`: 주차 선택과 역할별 입장
- `50plus_AI_Week1.html`: 강사용 강의안, 22페이지와 시연 기능 (강사소개 7단계 포함)
- `practice-week1.html`: 수강생 전용 실습장, 6개 실습
- `50plus_AI_Week2.html`: 질문·답변, ChatGPT의 맞춤형 지침·메모리, Google AI Studio 사용, 기획·제작·수정, 서버·배포 강사용 강의안, 39장 (암호화)
- `practice-week2.html`: 2주차 수강생 실습장
- `assets/`: 공통 글꼴과 글꼴 라이선스
- `.nojekyll`: 정적 파일 게시 설정

표지에서 ‘수업 시작하기’를 누르면 강사소개가 열립니다. 첨부된 강사소개 PDF의 7페이지를 원래 순서대로 보여주며, 다음 버튼과 포인터로 한 단계씩 넘깁니다. 소개가 끝나면 기존 수업 내용으로 이어집니다. 강사소개는 강사용 강의안에만 포함됩니다.

1·2주차가 열려 있으며, 3·4주차는 준비 중입니다.

## 1주차 수강생 실습

수강생에게 `practice-week1.html` 주소를 안내합니다. `#activity-1`부터 `#activity-6`까지 특정 실습으로 직접 이동할 수 있습니다.

1. 재료로 요리 추천받기 (제로샷)
2. 예시 따라 쓰기 (퓨샷)
3. 역할 정해 사진 정리하기 (수강생이 역할 직접 입력)
4. 풍경 이미지 설명하기
5. 소개 카드로 웹 기술 익히기 (HTML → CSS → JavaScript, 단계별 프롬프트 복사)
6. 만들고 싶은 것 정리하기

입력한 내용과 완료 표시는 사용하는 기기의 브라우저에 저장됩니다. 강의안의 시연 데이터와 다른 저장 공간을 사용합니다. 자동 저장을 사용할 수 없으면 안내 문구가 나타납니다. 상단의 ‘내 실습 내용 저장’으로 텍스트 파일을 내려받을 수 있습니다.

프롬프트는 사용 중인 AI 서비스에 붙여넣어 실행합니다. 실습장 자체는 AI를 호출하지 않습니다.

## 2주차 수강생 실습

수강생에게 `practice-week2.html` 주소를 안내합니다. 기획 시트는 강사가 제공하며, 실습장에서 기획 시트를 새로 생성하지 않습니다.

대상과 문제 → 필수·선택 기능 → 기획안 → 웹페이지 제작 → 실행·캡처·수정 → HEX 색상 → 디자인 레퍼런스 → 최종 확인 순서로 진행합니다. 각 단계에서 수강생이 먼저 판단하고 AI의 질문·대안을 검토한 뒤 결정을 기록합니다. 복사할 수 있는 프롬프트 8개, HTML에 포함된 실제 참고 사이트 캡처 2개, 색상 미리보기와 완료 확인을 포함합니다.

AI가 실행 도구를 사용할 수 있으면 직접 열고 클릭하고 캡처하도록 요청합니다. 도구가 없으면 수강생이 실행·캡처하여 AI에 전달합니다. 화면 캡처와 실제 기능 동작 확인을 구분합니다.

## 게시

HTML 파일과 assets 폴더를 저장소 루트에 함께 둡니다. 현재 저장소는 master 브랜치의 루트에서 GitHub Pages를 게시합니다. 수정한 파일을 커밋하면 자동으로 배포합니다.

## 강의안 비밀번호

강의안은 비밀번호를 입력해야 열립니다. 새로고침과 재방문 시 다시 입력하며, 상단의 ‘잠금’으로 입장 화면으로 돌아갑니다. 비밀번호는 브라우저 저장소에 저장하지 않습니다. 수강생 실습장은 비밀번호 없이 사용합니다.

배포 파일에는 강의 HTML을 gzip으로 압축한 뒤 PBKDF2-SHA256(600,000회)와 AES-256-GCM으로 암호화한 데이터만 포함합니다. 편집용 평문 원본은 게시 폴더 밖에 보관하고, 수정 후 다시 암호화해야 합니다. 비밀번호나 복호화 키를 저장소에 커밋하지 마세요.

이 방식은 정적 페이지를 잠그는 기능입니다. 공개 저장소의 이전 커밋이나 이미 다운로드한 과거 강의안까지 비공개로 바꾸지는 않습니다.

## 1주차 포인터와 마우스 이동

강의안에서 리모컨의 Page Down/Page Up, 방향키, Space/Shift+Space, Enter, N/P, Backspace를 지원합니다. 슬라이드 본문 왼쪽 클릭은 다음, 오른쪽 클릭은 이전 설명으로 이동합니다. 인포그래픽 설명은 한 단계씩 진행됩니다. 입력창·버튼·텍스트 선택·드래그·열린 대화상자의 기본 동작은 유지합니다.


## 2주차 강의안 조작

모든 장표에서 포인터·리모컨의 방향키, Page Down/Page Up, Space/Shift+Space, Enter, N/P, Backspace로 이동합니다. 본문 왼쪽 클릭·터치는 다음, 오른쪽 클릭은 이전 설명으로 이동합니다. 일반 장표와 Q&A·MVP·지침·메모리·AI Studio·배포 모션 모두 지원하며, 단계가 있는 장표는 설명부터 한 단계씩 진행합니다. 버튼에 초점이 남아 있어도 방향키·Page Down/Page Up은 이동에 사용하고, Enter·Space는 해당 버튼을 실행합니다. 길게 누르는 반복 입력으로 여러 장을 건너뛰지 않습니다.

목차·전체 보기·강사 메모·전체화면·인쇄를 지원합니다. 입력창, 복사·확대·재생 버튼, 링크, 텍스트 선택·드래그, 열린 대화상자의 기본 동작은 유지합니다. 강의안의 잠금과 학생 실습장 링크는 상단에 있습니다.

1~4쪽은 지난 시간 질문과 답변입니다. 개발자 도구의 역할, 일반 사용자에게도 개발자 도구를 제공하는 이유, 웹페이지의 앱 전환, 카페24 연동을 질문별로 설명합니다.

5~7쪽은 ChatGPT의 맞춤형 지침·메모리·이번 요청을 설명하는 클릭 모션입니다. 맞춤형 지침은 설정에 직접 정해 둔 답변 방식, 메모리는 대화에서 기억해 둔 사용자 정보·선호, 이번 요청은 지금 답변에 새로 부탁한 내용으로 구분합니다. 처음 화면에서 멈추며, 본문 클릭·방향키·하단 ‘다음 설명’ 버튼으로 한 단계씩 진행합니다. ‘이전 설명’과 ‘다시 보기’로 되돌릴 수 있고, 마지막 설명 뒤에는 다음 장표로 이동합니다. 전체 보기와 인쇄에서는 완성된 도식을 보여주며 발표 보기로 돌아오면 진행 상태가 복원됩니다. 질문·답변과 지침·메모리의 상세 설명은 기존 ‘강사 메모’에서 확인합니다.

기존 강의는 8쪽 표지부터 이어집니다. 9쪽은 기획(대상과 문제 정의) → 기능 정의 → 설계 → 디자인 → 구현 → 배포의 전체 과정을 보여줍니다. 하단의 여섯 단계 표시에서 현재 장표가 다루는 단계를 강조합니다. 표지·전체 과정·수업 흐름에서는 ‘전체 과정’을 표시합니다.

11쪽은 오늘 사용할 도구인 Google AI Studio를 소개합니다. 첨부 화면의 실제 워드마크와 함께 브라우저에서 질문하기, 내 자료를 첨부하기, 요청을 고치며 비교하기를 설명합니다. 14쪽은 기존 13쪽의 기획 템플릿 작성 안내입니다. 바로 뒤인 15~19쪽에서 첨부된 화면 순서대로 Playground → ＋ → Drive → 작성한 사본 선택 → 첨부 확인·검토 요청·Run을 보여줍니다. 현재 모델명이나 요금·무료 한도를 단정하지 않습니다.

24쪽은 MVP의 뜻, 25쪽은 MVP를 사용하는 이유를 설명합니다. 전체 과정과 두 MVP 모션그래픽은 각각 10초 재생한 뒤 멈춥니다. 일시정지·다시 보기를 지원하며, 다른 장표로 이동하면 재생이 멈춥니다. 전체 보기와 인쇄에서는 완성된 도식을 보여줍니다. 새로 추가한 질문·답변과 모든 모션그래픽도 강의안과 함께 암호화되어 있습니다.

35쪽의 디자인 적용 프롬프트는 ‘첨부된 디자인 참고해서 내 웹 페이지에 적용해줘’이며, 복사와 크게 보기에서도 동일한 문구를 사용합니다.

36~39쪽은 서버와 배포를 설명하는 클릭 모션입니다. 내 컴퓨터 → 서버 → 방문자의 흐름, 직접 배포와 GPT에 부탁하는 배포의 공통 원리, 진행 방법의 차이, GPT 이용료와 웹 운영비를 차례로 설명합니다. 각 장은 두 번 클릭하면 설명이 완성되며 하단 현재 단계는 ‘배포’를 표시합니다. 앞의 지침·메모리와 동일한 이동·다시 보기·전체 보기·인쇄·강사 메모 기능을 사용합니다.

배포 설명은 GPT에 배포 도구가 연결되어 있고 내 호스팅 계정에서 작업을 허용한 상황을 가정합니다. 특정 서비스의 현재 요금이나 무료 한도를 제시하지 않으며, ChatGPT 이용 조건·호스팅 요금제와 사용량·선택한 도메인이나 AI API 등의 비용을 구분합니다. 새 장표와 메모도 강의안 내부에 암호화되어 있습니다.
