# 오늘 점심 뭐 먹지? PRD

## 목적과 대상
점심 메뉴를 빠르게 고르고 싶은 직장인이 예산과 음식 종류를 선택해 후보를 확인한다.

## 핵심 사용 흐름
예산 선택 → 음식 종류 선택 → 추천받기 → 메뉴 확인 → 조건 변경 후 다시 추천

## 입력
- 1인 예산 상한: 8,000원 / 10,000원 / 15,000원
- 음식 종류: 한식 / 중식 / 양식 / 상관없음

## 필수 기능
1. 두 조건을 선택한다.
2. 추천 버튼을 누르면 제공된 예시 메뉴 목록에서 조건에 맞는 메뉴를 찾는다.
3. 후보가 3개보다 많으면 중복 없이 3개를 골라 보여준다. 후보가 1~2개면 있는 만큼만 보여준다.
4. 결과 카드에 메뉴명, 예시 가격, 음식 종류, 조건에 맞는 이유를 표시한다.
5. 후보가 없으면 결과 없음 안내와 조건 변경 방법을 보여준다.
6. 조건을 바꾸고 다시 추천하면 이전 결과를 새 조건의 결과로 교체한다.

## 화면과 상태
한 페이지의 소개·조건 선택·추천 버튼·결과 영역으로 구성한다.
추천 전 / 결과가 있는 상태 / 결과가 없는 상태를 구분한다.
가격은 수업용 예시임을 표시한다. 모바일에서도 글자와 버튼이 잘 보여야 한다.

## 데이터와 범위
제공한 예시 메뉴 12개를 사용한다.
로그인, 식당 검색, 위치 정보, 주문·결제, 실시간 가격 조회, 별도 AI API는 포함하지 않는다.

## 완성 기준
- 8,000원 이하 + 중식: 짜장면과 볶음밥 2개만 표시한다.
- 8,000원 이하 + 양식: 조건에 맞는 메뉴가 없다는 안내를 표시한다.
- 15,000원 이하 + 상관없음: 조건에 맞는 메뉴 3개를 중복 없이 표시한다.
- 조건을 바꿔 다시 추천하면 이전 결과가 남지 않는다.
- 휴대폰 크기에서도 조건 선택·추천·결과 확인이 가능하다.
