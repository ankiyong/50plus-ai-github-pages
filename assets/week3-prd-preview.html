수업용 요약 예시

01 · 대상과 목표

직장인의 점심 메뉴 고민 시간 감소
예산과 취향에 맞는 후보 추천

02 · 입력

예산: 8천 / 1만 / 1만 5천 원 이하
종류: 한식 / 중식 / 양식 / 상관없음

03 · 핵심 기능

조건 선택 → 추천 실행 → 결과 보기
중복 없이 최대 3개 · 조건 변경 후 재추천

04 · 결과와 예외 처리

메뉴명·가격·종류·추천 이유 표시
후보 0개: 결과 없음과 조건 변경 안내

05 · 완성 기준

8,000원 이하 + 중식 → 짜장면·볶음밥 2개만 표시
8,000원 이하 + 양식 → 후보 없음 안내
조건 변경 후 재추천 → 이전 결과를 새 결과로 교체

06 · 제작 범위

수업용 메뉴 12개 사용 · 로그인·실제 식당 검색·주문 제외
